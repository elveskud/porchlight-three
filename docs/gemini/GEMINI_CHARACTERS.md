# Gemini: pose sheets for the 10 new characters (Episodes 4–13)

One pose sheet per character. I copy each character's look into code from their sheet; Gemini's drawings never appear in the episodes.

For each one:
1. Start a new Gemini chat.
2. Attach the picture named on the "Attach" line.
3. Paste the prompt.
4. Save the result in `art/gemini/refs/` under the name in its heading.

Every prompt ends with the same style block, so it's included in each one.

---

### 1. `poses_walt.jpg`
Attach: `art/gemini/characters/03_walt.jpg`
```
Image 1 shows Walt, a warm, stocky father fox from a 2D cartoon series. Draw him, keeping his exact design, colours, clothes and proportions, seen from the FRONT like in image 1.
A pose sheet, 8 poses in two rows, all the same scale, each one separate:
1) carrying a big dish of food with both paws, proud
2) laughing warmly, one paw on his belly
3) arms open wide, welcoming guests
4) a quiet, sad look, eyes down, tea towel in his paws
5) leaning on a doorframe, gentle smile
6) one paw on someone's shoulder (just the arm reaching out)
7) pointing to a chair, "sit, sit"
8) holding up an old framed photo, looking at it fondly
Draw ONLY the character. Bold clean black outlines, flat solid colours with ONE darker shadow tone, no texture. Plain white background. NO text, NO labels, NO numbers.
```
