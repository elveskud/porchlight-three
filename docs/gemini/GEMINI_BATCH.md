Every prompt has the style built in, so you can paste each one on its own.

**How to use it**
1. Open a new Gemini chat for each prompt.
2. Attach the picture named on the "Attach" line, then paste the prompt. The attachment keeps the style close, so don't skip it.
3. Save the result with the exact name in the heading into `art/gemini/new/`. I'll sort and upscale them from there.
4. If a picture has words, extra characters or painted fireflies, say "Redo it without the ..." in the same chat.

**Characters are design references.** Your rule is that the cast stays code-drawn, so I copy each design in code. The looks below are my proposals, so change anything you like before you paste it.

**Already made, so not listed here:** the hall outside (day and night), classroom, Mrs. Brook's porch, main street, Walt's dining room (evening and storm), Walt's hallway, grandpa's photos, the townsfolk (`1121.jpg`), the die, the box, the board and the pieces.
