**How to use it**
1. Open a **brand-new Gemini chat for every prompt**. This matters most for 41–47: they came back as the festival stage because Gemini kept using an earlier picture from the same chat.

3. Before saving, check the "Check" line. If it's wrong, say "Start again from the picture I attached" in the same chat.
4. Save with the exact name in the heading into `art/gemini/new/`.
